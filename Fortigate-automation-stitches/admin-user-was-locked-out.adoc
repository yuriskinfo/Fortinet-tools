= Email alert on multiple failed log in attempts

_Task_: When some IP address gets locked out for multiple failed admin-level login attempts, send email alert 
for possible brute-force attack.

* Trigger
----
config system automation-trigger
  edit "Admin-user-was-locked-out"
        set event-type event-log
        set logid 32021
    next
end
----

* Action

----
config system automation-action
    edit "Default Email"
        set description "Default automation action configuration for sending an email with basic information on the log event."
        set action-type email
        set email-to "fgt@yurisk.info"
        set email-subject "%%log.logdesc%%"
    next
end
----

* Stitch

----
config system automation-stitch
    edit "Admin-user-was-locked-out"
        set trigger "Admin-user-was-locked-out"
        config actions
            edit 1
                set action "Default Email"
                set required enable
            next
        end
    next
end
----
